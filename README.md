# Retail Funnel Analysis using SQL

## Overview
This project analyzes user behavior in an e-commerce funnel using SQL.

It is a continuation of a prior Python EDA, where the same dataset was explored visually.

## Approach

This project follows two phases:

### 1. Exploration (Working SQL)
- Contains all intermediate queries and experiments
- Used to understand patterns and test logic

### 2. Final Analysis (Clean SQL)
- Structured and optimized queries
- Focused on business insights

## Key Insights
- Add-to-cart is the strongest signal of purchase intent
- Major drop-off occurs between add_to_cart and purchase
- High-activity sessions without purchase indicate decision friction

## Files
- Retail_SQL_Final.sql → Clean structured queries
- Retail_SQL_Working.sql → Full exploratory queries
